# 架构与源码

Mimic 目前是单实例模块化单体。核心持有会话、权限、预算、版本和最终发送；插件实现协议或能力，不独立操作核心数据库。

| 目录                | 职责                                                           |
| ------------------- | -------------------------------------------------------------- |
| packages/contracts  | 消息、Workspace、Scope、模型、记忆、存储、工具和插件契约       |
| packages/core       | 归一消息入库、上下文筛选、参与决策、群风格、可靠记忆摄取与发送 |
| packages/ai-runtime | 唯一的连接/凭据/预算/用量入口及受限记忆 broker                 |
| packages/plugin-sdk | 注册、权限、命名空间数据和作用域服务                           |
| packages/scheduler  | cron、随机与一次任务，持久化抽样/租约/执行记录                 |
| plugins             | QQ、模型 codecs、MemStation、SQLite/Drizzle、Safety 和内置工具 |
| apps/daemon         | 服务装配、控制 API、QQ Webhook、生命周期与恢复                 |
| apps/dashboard      | SvelteKit + Svelte + Bits UI 的本地管理面板                    |
| examples            | 自定义插件、管理页和 Soul 示例                                 |
| tests               | 确定性回归、浏览器、回放材料与可选跨项目测试                   |

## 对话与身份

协议适配器产生统一 Message。Workspace 隔离群/私聊，Actor ID 区分发言人；昵称只用于展示，引用不自动归到当前作者。协议通过 coverage 返回当前接收范围，配置变化后每次决策读取最新值。

参与决策与生成分开。决策先判断兴趣、贡献、时机、指代和场合，生成模型再组织语言或调用工具。完整消息可见性、原生概率、授权、冷却和安静时段共同限制主动参与；提及不等于强制回答。

## 上下文与响应开销

决策与回复分别组装上下文。默认回复最多保留 16 条、序列化后 6,000 字符的近期消息；决策最多 8 条、4,000 字符。优先保留当前触发、两层引用关系，再按时间填入最新消息，包括机器人已确认发送的回复。身份、引用和未解析附件数量仍保留，协议投递字段不进入提示。单条正文最多展示 2,000 字符，引用最多 600 字符，截断会明确标记；超出预算且无法保留触发元数据时拒绝该轮，不能假装看到了完整内容。

人格在回复的 system 消息中保留一份。召回记忆默认最多 3 条、1,800 字符，只选择完整且带来源的条目；原始来源版本仍在发送前验证。记忆通过内容安全检查后才进入生成，失败时省略记忆并继续基于当前对话回答。已有群风格仅给参与决策提供简短先验，画像更新移至当前回复结束或发送之后，仍受原运行的取消与超时控制。

单次工具结果默认最多 4,000 字符，包含 JSON 转义和截断标记的开销。生成请求的完整 messages 与 tools 默认硬限 24,000 字符，包含后续工具回合和安全重写；超限在请求发出前失败。所有限制位于配置的 `context` 对象，旧配置加载时自动补齐默认值。字符限额与厂商 tokenizer 无关，不能当作真实 token 数。

相同运行、工作区、配置版本和完整正文的最终安全审查可在 30 秒内复用于发送检查；修改正文、过期或切换配置都会重新审查，失败和审计模式的放行不缓存。消息版本、记忆来源、发送 hook 与发送预留仍逐次检查。

## 可靠性

输入去重与版本保存在 SQLite，消息与记忆 pending_policy 占位同事务提交。Safety 通过后才冻结远端投递正文；结果未知时复用同一幂等键，不把绑定变化后的旧作业自动转投新后端。

输出在发送前检查消息/配置版本、来源与权限。发送预留、协议投递与回执分别记录；重启后不重发未知结果。机器人只有确认投递后进入长期记忆，撤回同样传播。

配置保存串行化并采用 revision CAS；新凭据引用只有在配置保存成功后激活。AI 请求的预算与网络操作绑定配置版本，防止旧模型参数发到新连接。模型插件只编解码，不拿厂商 Key 或数据库句柄。

## 扩展边界

普通插件经作用域服务访问 AI、记忆和自己的数据；管理页在构建时静态注册。当前进程内第三方插件必须可信；TypeScript 权限接口不是操作系统隔离。模型生成的代码仅进入独立代码沙箱。

具体插件只在 daemon 装配层导入。核心通过 SafetyProvider 和工具声明执行管线，AI Runtime 通过注册的 ModelProvider 编解码；两者不导入具体模型或工具实现。默认安全插件与第三方插件走同一 SDK，安全决策可独立路由到 decision model；规则及供应商协议属于插件，权限、作用域、预算、取消和最终发送属于宿主。

更多接口见 [插件开发](plugins.md)，记忆身份/受众与 broker 接线见 [MemStation 接入](memstation.md)。
