# Mimic character art

The character portrait was generated specifically for Mimic on 2026-10-25 using an AI image generation tool. It is an original design brief and is not intended to depict a character from an existing series. No external font is bundled.

| File | Use |
| --- | --- |
| mimic-anime-master.png | Original 1254 × 1254 transparent master |
| ../../apps/dashboard/static/brand/mimic-avatar.png | 256 × 256 Dashboard avatar |
| ../../apps/dashboard/static/favicon-32.png | Small browser icon |
| ../../apps/dashboard/static/favicon-192.png | Large browser icon |
| ../../apps/dashboard/static/apple-touch-icon.png | Apple touch icon |

Deployment sizes were derived with macOS sips. The master is retained so contributors can regenerate sizes without resizing an already reduced image. These project assets are distributed with Mimic under its Apache-2.0 license; third-party trademark rights are not granted.
