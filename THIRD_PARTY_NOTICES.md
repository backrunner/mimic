# Third-party notices

Mimic is Apache-2.0. Dependencies retain their own licenses. This inventory records the installed Node dependency graph, including development tools; optional platform binaries differ by installation. No dependency source or binary is vendored here.

License and notice texts shipped by the installed packages are collected in [LICENSES/third-party.txt](LICENSES/third-party.txt). Supplementary upstream notices and their pinned sources are in [LICENSES/upstream](LICENSES/upstream). Keep original package notices when redistributing dependencies or build output.

Regenerate after dependency changes with `node scripts/third-party-notices.mjs`.

## Build and runtime

Lightning CSS and its native binding are MPL-2.0 build tools. Their source is not modified or vendored by Mimic. Node.js, container base images, Go, PostgreSQL/pgvector, Redis and any separately deployed MemStation installation have their own licensing; this Node package inventory does not relicense or inventory those external distributions.

The two Rich Harris packages is-reference and locate-character declare MIT in their published metadata/README without shipping a standalone license file; this is recorded in the collected notices rather than presented as an absent license.
